Setup

In machine learning tasks, we are interested in learning something about a function or joint probability distribution, given only a set of random samples from that distribution. For example, supposing that there exists some function $f: \X \to \Y$, we might be interested in trying to learn $f$ from a set of samples, $(x_i,f(x_i))_{i=1}^n \in (\X\times\Y)^n$. Here, we typically assume that the $x_i$’s are drawn from some distribution $\mu_X$, which combined with the (degenerate) conditional distribution $P(Y=y|X=x) = \delta(y-f(x))$, gives us a joint distribution $\mu_Z$ over $\Z := \X\times \Y$.

A machine learning algorithm is a rule $A$ which takes in a data set $(x_i,f(x_i))_{i=1}^n \in (\X\times\Y)^n$ and outputs a member of some hypothesis class, $\H$. Ideally, we would like to select $h$ to be equal to $f$. But this objective is far too strong in general; we need rather a statistically meaningful way of measuring how well $h$ approximates $f$. The following heuristic will guide us to such a metric: If we sample an unseen $(x_i,y_i)$ from $\mu_X$, we want this point to be “close” to the corresponding point $(x_i,h(x_i))$ constructed by our chosen hypothesis $h$. To quantify this “closeness”, we define a loss functional, $\phi: \Y \times \Y \to \R$, such as the common $\ell_2$ loss, $\phi(y,y') = |y-y'|^2$. The expected value of this loss, when $x_i$ and $y_i$ are sampled from the unknown joint distribution, $\mu_Z$, is known as its risk,

$$\tag{}R(h) = \mathbb{E}_{(x,y)\sim\mu_Z}[\phi(y,h(y))].$$

The information-theoretic and computational questions of machine learning

Given the setup that we have considered, a basic question to ask is this: Given some (infinite) input domain $\X$, a simple output domain such as the set of binary outputs $\Y = \\{0,1\\}$, a loss functional $\phi$, and a set of samples from some unknown distribution $\mu_Z$, what can we learn? For example, ignoring computational considerations, can we identify the optimal hypothesis $h^*$ from the space of all possible functions $h: \X \to \Y$? And if so, what guarantees can we make about the goodness of this hypothesis in terms of the risk? For example, can we guarantee that the risk will approach zero with high probability as the size of our dataset (the number of samples from $\mu_Z$) becomes large?

Starting from the problem statement that we have given, we quickly reach a very negative result in the form of the so-called “No-free-lunch Theorem.” The no-free-lunch theorem states that learning is simply impossible without introducing certain prior knowledge or assumptions.

This sounds bad, but it has to be caveated. Indeed, if we think carefully about what the no-free-lunch theorem is saying, we will begin to question whether it is really telling us anything important or practical. This is because, of the full space of possible functions that we could in principle consider, we are never interested in a vast majority of them—almost all of them, to be more precise. These are the functions which have no actual structure to be learned. If we throw out these functions, things start to look a bit different.

We can go a little further in this direction and start to acknowledge that not only do we want some structure, but we we are really only interested in functions which have enough structure to be compactly representable via a computer program. As soon as we set some maximum program length of interest, all of the problems of inference vanish.

This understanding calls into question two of the main ways in which the no-free-lunch theorem is traditionally applied. It is common pedogogy to use the no-free-lunch theorem to motivate the idea that there is no universal learner, and therefore we we must use specific prior knowledge of a problem in order to select a learning algorithm which will not fail on that problem. In practice, when we restrict to real-world conditions, neither of these conclusions is true.

On the other hand, it is a reality of machine learning practice that algorithms are tailored to their problem domains. We will finish the post by considering the practical reasons why this is the case, and how it allows us to understand the practice of modern machine learning as well as its long term prospects and limitations.

The no-free-lunch theorem and information-theoretic limits of learning

The no-free-lunch theorm says that, given only the information contained in the problem statement as we have posed it, there is no optimal hypothesis. Said differently, there is no universally optimal learning algorithm. Moreover, for any particular learning algorithm that we choose, it is impossible to make guarantees about the convergence of the risk to zero. Instead of going through the formal theorem, let’s try to convince ourselves intuitively that this result is to be expected.

Let’s restrict to the case where the data are samples from an unknown target function $f: \X \to \Y$. Whenever we select a hypothesis, $h \in \Y^\X$ (this notation denotes the space of all functions from $\Y$ to $\X$), on the basis of some finite number of samples from a target function $f$, we are making a choice about how to interpolate or extrapolate from the function’s evaluations at those samples to its evaluations at an infinite number of other points, i.e. $\X \setminus \\{x_1,x_2,...,x_n\\}$. For this reason, the particular way in which a machine learning algorithm chooses or generates its hypothesis is known as its inductive bias, since the choice entails inducing the values of a function at unobserved points from its values at observed points. The choice of an inductive bias is not informed by the data itself. In fact, for the problem as we have defined it, there is no problem-specific basis for making the choice; we simply have to hope that there is a single choice that will work well enough for all problems.

But is this a reasonable hope? It turns out that if we believe that it is reasonable—that is, if we believe that there should be a single way of doing induction that could work for all possible problems—then we are failing to consider the full space of possible functions (or more generally joint distributions). We have unwittingly made any number of assumptions about the smoothness of the target function, continuity of the joint probability distribution, etc. But if we could somehow rid our intuition of these accompanying ideas, the hope of a universal inductive bias would vanish.
