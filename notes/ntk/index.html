NTK: From Zero to Hero

I want to try doing a thread on (demystifying) the Neural Tangent Kernel (NTK). When I first learned about the NTK, I felt like it was a completely unexpected and even bizarre result. And yet, I would sometimes see people characterize it as somewhat obvious. Happily, over time, things have popped into place so that the NTK now looks quite natural to me as well. In this thread, I’d like to present that perspective.

Before we begin, we need to understand something about kernels and kernel methods. The mathematics of kernel methods can look quite intimidating as it involves things like Reproducing Kernel Hilbert Spaces (RKHS’s). However, the basic concepts can be made quite accessible. Any kernel method stars with a kernel, $k(x,y) : \X^2 \to \R$, where $\X$ is the domain on which our data lives. $k$ needs to satisfy certain properties which we will discuss later. Given a kernel $k$, we can define a family of functions having the form

$$ f(x) = \sum_{i=1}^n a_i k(x,x_i). $$

This family of functions more or less constitutes the RKHS associated with the kernel. Associated with each function within the space, we have a norm, $||f||^2 = \sum_{i=1}^n\sum_{j=1}^n a_ia_j k(x_i,x_j).$

Now, kernel (ridge) regression involves finding the (smallest norm) function within an RKHS that interpolates a set of data points. More precisely, finding the solution to the optimization problem

$$ \min_{f \in \H(k)} \sum_{i=1}^n|f(x_i)-y_i|^2 + ||f||^2 $$

But due to a result by the name of the representer theorem, we know that the solution to this optimization can always be represented using only the $x_i$’s of the data we are trying to fit. Thus, kernel regression is really just trying to find an $a_i$ for each $x_i$ in the training data.

Let’s now return to the NTK. The NTK was introduced in [], where they showed that in a certain limit as a deep neural network becomes wide, training the network is the same as doing kernel ridge regression with a particular kernel, known as the neural tangent kernel. In particular, for a network $h: \Theta\times \X \to \R$ where $\theta$ is the parameter space for the network, they showed that the NTK had the form

$$ k(x,y) = \nabla_w h(w;x)^T \nabla_w h(w;y). $$

You can see the basis of name neural tangent kernel in the fact that the kernel is constructed using gradients of the network.

The interesting implication of this result is that it says that for very wide networks, the “off-training-data” behavior of the learned model will be goverend by the NTK. In particular, it says that if the gradient of the output of the network with respect to the network parameters is similar when evaluated at two different points (as measured by the inner product), we can expect the output of the trained network to be similar. In this way, the network is somewhat similar to a weighted nearest neighbors model, with the weighting determined by the similarity of the gradients.

Now, this description may sound very surprising. It doesn’t seem to line up with any of our typical mental models for understanding neural networks. So how do we resolve this suprise and make the result appear obvious?

There are two things we need to understand:

  1. First, we need to note a correspondence between kernel methods and linear models. For every feature space associated with a linear model, there is a corresponding RHKS.
  2. Next, we “simply” need to show that as a network becomes wide, it also becomes linear.
